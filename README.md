# FastAPI Cloud

You code. We cloud.

Deploy your FastAPI app in seconds, just run:

```bash
fastapi deploy
```

With a single command, skip the hassle and get your app running in the cloud effortlessly.

Learn more at [https://fastapicloud.com](https://fastapicloud.com).
